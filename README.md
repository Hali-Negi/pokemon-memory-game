# pokemon-memory-game

This is a dynamic memory card game built using HTML, CSS, and JavaScript. Players flip cards to match pairs of Pokémon. The game uses the PokéAPI to retrieve real Pokémon images and offers multiple interactive features including a timer, difficulty settings, and a one-time power-up.

## Features

- Flip-to-match gameplay using Pokémon cards
- Real-time Pokémon images fetched from the PokéAPI
- Countdown timer with game over logic
- Win condition when all pairs are matched
- Easy, Medium, and Hard difficulty levels
- Light and Dark mode theme switcher
- One-time power-up: temporarily reveals all cards
- Start and Reset functionality

## How to Play

1. Select a difficulty level.
2. Click "Start Game" to begin.
3. Flip two cards to find matching Pokémon.
4. Match all pairs before the timer runs out to win.
5. You may use the power-up once per game to reveal all cards briefly.
